# How to Eat a Grape

This project explores the complex and often misunderstood process of eating a grape. From gripping the grape without squishing it, to aligning it with your mouth without launching it across the room, every step was a journey. Biggest challenge? Fighting the urge to juggle. Biggest triumph? No choking. Major takeaway? Grapes are slipperier than they look.

bool grapeIsHeld = true;
bool mouthIsOpen = true;

void setup() {
  Serial.begin(9600);
  Serial.println("Initializing grape consumption protocol...");
}

void loop() {
  if (grapeIsHeld && mouthIsOpen) {
    Serial.println("Bringing grape to mouth...");
    consumeGrape();
  } else {
    Serial.println("Grape missing or mouth not ready.");
  }

  delay(3000); // thinking break
}

void consumeGrape() {
  Serial.println("Grape consumed. You win.");
}
